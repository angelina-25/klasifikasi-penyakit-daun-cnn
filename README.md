
# Klasifikasi Penyakit Daun Tanaman

Aplikasi klasifikasi penyakit daun tanaman menggunakan metode Custom Convolutional Neural Network (CNN) dan dataset PlantVillage.

## Kelas Klasifikasi

1. Apel - Apple Scab
2. Apel - Sehat
3. Jagung - Karat Daun
4. Kentang - Hawar Daun Akhir
5. Tomat - Sehat

## Teknologi

- Python
- TensorFlow / Keras
- Streamlit
- NumPy
- Pillow

## Fitur Aplikasi

- Upload gambar daun tanaman.
- Klasifikasi penyakit daun menggunakan CNN.
- Menampilkan hasil prediksi.
- Menampilkan probabilitas setiap kelas.

## Cara Menjalankan

Install library:
pip install -r requirements.txt

Jalankan aplikasi:
streamlit run app.py
